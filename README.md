## 📌 Overview

A comprehensive frontend replica of the **Myntra** fashion marketplace. Recreates the iconic header navigation, promotional hero banners, multi-category fashion grid, and interactive bag/cart counter.

---

## ✨ Key Features

- **Myntra-Style Sticky Navigation:** Multi-level dropdown menus for Men, Women, Kids, Home & Living, and Beauty.
- **Responsive Product Grid:** Card layouts showcasing brand names, descriptions, original vs discounted prices, and discount percentages.
- **Wishlist & Bag Interaction:** Dynamic shopping bag counter and wishlist state feedback.
- **Mobile Responsive Breakpoints:** Adapts smoothly across all modern screen resolutions.

---

## 💻 Tech Stack & Architecture

- **Frontend Core:** Semantic HTML5, Modular CSS3, JavaScript ES6+
- **Layout Systems:** CSS Flexbox, CSS Grid, Media Queries
